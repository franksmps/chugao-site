CGC-48W — Controladores LED de interior (50-400W)

CGC-48W indoor LED driver, 12V / 24V, narrow metal case.

Resumen

The CGC-48W is a 48W indoor driver in a narrow metal case for 12V or 24V fixtures. Active PFC, fan-less, four protections, CE/RoHS standard, 3-year warranty.

  • Power: 48W
  • Salida: DC 12V / 24V
  • Protección de ingreso: IP20
  • Entrada: AC 190-264V
  • Certification: CE / RoHS; UL on request

Typical applications

CE and RoHS are standard on every CHUGAO unit. UL is available per model (4-6 weeks from order confirmation). BIS (India) is available on request for selected models. Certificate PDFs are sent before you place the order.
