CGM-60W — LED 适配器（5-200W）

60W AC/DC LED adapter, 12V / 24V output for longer strip runs.

概览

The CGM-60W is a 60W AC/DC adapter for 12V or 24V LED strips and modules. Universal 100-240V input, local plug fitted per market, CE/RoHS standard and a 3-year warranty.

  • Power: 60W
  • 输出： DC 12V / 24V
  • 防护等级: IP20
  • 输入： AC 100-240V
  • Certification: CE / RoHS; UL on request
