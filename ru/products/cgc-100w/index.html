CGC-100W — Внутренние драйверы LED (50-400 Вт)

CGC-100W indoor LED driver, 12V / 24V, narrow metal case.

Обзор

The CGC-100W is a 100W indoor driver in a narrow metal case for 12V or 24V fixtures. Active PFC, fan-less, four protections, CE/RoHS standard, 3-year warranty.

  • Power: 100W
  • Выход: DC 12V / 24V
  • Степень защиты: IP20
  • Вход: AC 190-264V
  • Certification: CE / RoHS; UL on request

Certification

CE and RoHS are standard on every CHUGAO unit. UL is available per model (4-6 weeks from order confirmation). BIS (Индия) is available on request for selected models. Certificate PDFs are sent before you place the order.
